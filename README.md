# kb99-1c-mini-sklad
Мини-Склад - учебная конфигурация 1С

О проекте

«Мини-Склад» - учебная конфигурация, разработанная на платформе «1С:Предприятие 8.3».

Состав конфигурации:

Справочники
1) Товары - хранение информации о товарах.
2) Контрагенты - хранение информации о поставщиках и покупателях.

Документы
1) Поступление - регистрация поступления товаров.
2) Реализация - регистрация продажи товаров.

Интерфейс

Создана подсистема «Мини-Склад», объединяющая основные объекты конфигурации. В ней доступны команды для работы со справочниками и документами.

Как открыть конфигурацию:

1) Скачать репозиторий с GitHub через Code > Download ZIP и распаковать архив.
2) Запустить платформу «1С:Предприятие 8.3».
3) Создать новую пустую информационную базу без конфигурации.
4) Открыть созданную базу в режиме «Конфигуратор».
5) Выполнить команду Конфигурация > Загрузить конфигурацию из файлов.
6) Указать папку выгруженными файлами конфигурации.
7) После загрузки выполнить Конфигурация > Обновить конфигурацию базы данных (F7).
